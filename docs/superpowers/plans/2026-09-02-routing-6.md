# Routing and evals, step 6 — public benchmark loaders (plan)

**Spec:** `docs/superpowers/specs/2026-09-02-routing-and-evals-design.md` §8 (benchmarks), §4.1 (`documents[]`, `source`). **Branch:** `routing-6`.

## Goal

`counsel-os eval import <set>` pulls a public legal benchmark, turns it into v2 fixtures the runner already understands (one fixture per task, `documents[]` per item, one vault per set), records its license, and never commits benchmark text to the repo. `counsel-os eval --set benchmark --all` then runs it like any other fixture.

## Shape

- `runtime/src/evals/benchmarks/` — `types.ts` (loader interface, `NotRedistributableError`), `csv.ts` (RFC 4180 + TSV), one file per set, `index.ts` (registry), `import.ts` (fetch → raw cache → fixtures + vault → `LICENSES.md`).
- Import writes `<dest>/<set>/fixtures/*.json`, `<dest>/<set>/vaults/<set>/` (a marked `config.md`, the practice seed under `practice/`, documents under `matters/<set>/`), `<dest>/<set>/raw/` (the downloads, reused unless `--refresh`), and `<dest>/LICENSES.md`. `dest` defaults to `evals/benchmarks/`, which is git-ignored.
- `loadBenchmarkFixtures(dir)` joins `loadFixtures`; `LoadedFixture.set` gains `'benchmark'`; `selectFixtures` gains `set`.
- CLI: `counsel-os eval import <set> [--subset n] [--tasks a,b] [--dest dir] [--refresh]`; `counsel-os eval --set benchmark|shipped|practice`.
- Tests run on committed samples under `runtime/src/evals/benchmarks/__fixtures__/` (a few real rows each, with a `NOTICE.md`); the fetchers are exercised against a fake `fetch`. No network in tests.
